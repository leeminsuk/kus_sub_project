# Coastal World → 121분의 1: 캠퍼스의 신호

기반 저장소는 `leeminsuk/coastalworld-local`입니다. 원본의 공개 웹빌드에는 편집 가능한 개발 소스가 포함되어 있지 않습니다. 캠퍼스판은 Next.js App Router와 TypeScript로 게임 흐름을 구성하고 Three.js 장면을 새로 만들었습니다. 원본 캐릭터·표정 아틀라스·리깅·애니메이션을 실제로 불러와 사용합니다.

| 원본 | 캠퍼스판 |
| --- | --- |
| 섬 단위 탐험 | 고려대학교의 석조 건축·중앙 잔디·학생 공간을 참고한 창작 캠퍼스 |
| 해안 마을의 NPC·퀘스트 | 캠퍼스 인물과 축제 신호를 복원하는 탐험 퀘스트 |
| WASD / 방향키 자유 이동 | 같은 화면 기준 이동, 부드러운 방향 전환과 추적 카메라 |
| 마우스를 누른 위치로 이동 | 캠퍼스 지면을 누르거나 이동 입력으로 자유 탐험 |
| 걷기·뛰기 자동 애니메이션 | 원본 Walk / Run 클립을 이동 상태에 맞춰 혼합 |
| 가까운 인물과 대화 | 근접한 NPC와 상호작용하여 대화·퀘스트 진행 |
| 브라우저 로컬 저장 | 캠퍼스 진행 상황을 별도 저장 키에 자동 저장 |
| 원본 정적 실행본 | `public/original`에 원본 진입 파일을 보존하고 공통 자산을 참조 |

## 실제 재사용 자산

- `public/assets/character.glb`: Draco 압축 원본 캐릭터. 몸체 658개 정점과 원본 의상 메시를 사용합니다.
- `public/assets/Character_Texture.png`: 원본 표정·의상 아틀라스. 눈·입은 녹색 채널 마스크와 애니메이션의 표정 참조 좌표로 표현합니다. 캠퍼스판의 의상 색만 입힙니다.
- `public/vendors/draco/`: 로컬 Draco 디코더. 외부 CDN 없이 모델을 해제합니다.
- 원본 GLB와 텍스처는 한 번 로드하고 NPC마다 골격을 복제합니다. 한 인물의 동작이 다른 인물의 골격을 바꾸지 않습니다.

원본 단일 `All_anims` 타임라인은 30fps 기준으로 다음과 같이 잘라 사용합니다. 아래 프레임 구간은 원본 `webgl` 번들에서 확인했습니다.

| 동작 | 프레임 |
| --- | --- |
| 기본 대기 Idle3 | 156–255 |
| 걷기 Walk | 3–27 |
| 뛰기 Run | 33–57 |
| 축하 Dancing | 947–979 |

원본 캐릭터 크기 배율 `0.89`, Walk 재생 배율 `0.9792`, Run 재생 배율 `0.9888`을 유지합니다. 원본 캐릭터의 전체 의상을 동시에 렌더링하지 않고 몸체·캡·백팩·운동화만 선택합니다. 표정 참조용 구체는 보이지 않게 처리하되 애니메이션 참조 노드는 유지합니다.

의상은 크림슨 몸체와 캡, 짙은 남색 백팩, 크림색 운동화로 조합했습니다. 몸체·눈·입의 원본 비율을 보존하면서 캠퍼스 분위기를 색으로 구분합니다. 인물별 요청 색을 몸체·캡에 적용하므로 NPC도 같은 세계의 캐릭터로 보입니다.

## 캐릭터 검증 근거

2026-10-13에 독립 Three.js 미리보기와 실제 Chromium 브라우저로 원본 모델의 로딩·표정·대기·뛰기 동작을 확인했습니다. `output/playwright/avatar-idle.png`, `output/playwright/avatar-run.png`에 로컬 검증용 실제 렌더링 캡처가 있으며 이 검증 중 JavaScript/WebGL 오류는 0건이었습니다. TypeScript 단독 타입 검사도 통과했습니다. 이 검증은 캐릭터 렌더링 검증이며 전체 게임의 퀘스트 검증을 대신하지 않습니다.

[캐릭터와 NPC 렌더링 캡처](verification-assets/avatar-npcs.png)도 저장소에 포함했습니다.

조사한 1차 자료:

- [사용자가 지정한 기반 저장소](https://github.com/leeminsuk/coastalworld-local): 인증된 로컬 clone의 README, `assets/webgl.js`, `assets/vendor.75f6e6ae65453426.js`, `assets/character.glb`를 직접 읽었습니다. 비공개 저장소여서 일반 웹 요청에는 표시되지 않을 수 있습니다.
- [Coastal World 원본 실행 사이트](https://coastalworld.merci-michel.com/): 원작 경험과 권리자 표시를 확인했습니다.
- [제작사 Merci-Michel 프로젝트 목록](https://www.merci-michel.com/projects/): 제작사의 Coastal Bank / Coastal World 프로젝트 표기를 확인했습니다.

외부에서 새 캐릭터 모델을 가져오지 않았습니다. 이미 포함된 원본 모델의 적은 정점 수, 완성된 리깅과 표정, 걷기·뛰기·축하 동작이 이 게임에 가장 잘 맞기 때문에 이를 선택했습니다.

## 구현 경계와 출처

캠퍼스 장면, 충돌, 퀘스트, UI와 저장 형식은 이 프로젝트에서 새로 구현했습니다. 원본의 모든 물리 코드나 미니게임을 그대로 이식한 것은 아닙니다. 캠퍼스는 실제 고려대학교의 정밀 측량 모델이나 공식 지도에 해당하지 않습니다.

원작은 Coastal Community Bank / Merci-Michel의 [Coastal World](https://coastalworld.merci-michel.com/)입니다. 원본 자산의 저작권과 기존 고지는 해당 권리자에게 유지되며, 새 코드가 원본 자산에 새로운 오픈소스 라이선스를 부여하지 않습니다. 이 작업은 사용자가 요청한 비공개 프로젝트로 구성합니다.
